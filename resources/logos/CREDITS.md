# Logo credits

Every file in this directory is a full SVG logo that can be referenced from a
glyph file by its file name, e.g. `(logo . docker)` for `docker.svg`.

(GNU AGPL-3.0-or-later). They show off what the full-SVG logo format can do:
several shapes, gradients, groups and transforms.
