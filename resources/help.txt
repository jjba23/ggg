GGG: Guile Glyph Generator
    Generate SVG images for useful glyphs, Org/Markdown badges and more,
    leveraging the power of Lisp (Guile Scheme).

    See more at: https://codeberg.org/jjba23/ggg
    Software licensed under the GNU AGPL v3 or newer.

    With flexible support for badges with any number of parts.

USAGE: ggg [OPTIONS]
OPTIONS:
    -f, --file FILE
        Specify the path to the glyph file (Scheme config) (required).

    -d, --destination DIRECTORY
        Specify the destination directory for the generated SVGs.
        Defaults to "./dist" but shouldn't be used if also using stdout.

    -i, --stdin
        Specify that ggg should read the glyph file from standard input
        (stdin) commonly done with a pipe in *nix systems (|).

    -o, --stdout
        Specify that ggg should output the generated glyphs to stdout
        instead of to files (typically to console).

    -c, --convert
        Specify that ggg should convert the SVG images to PNGs after
        generation, using ImageMagick and falling back to Inkscape.
        Cannot be used with stdout.

    -k, --keep
        Keep the files already present in the destination directory
        instead of clearing it. Useful to render several glyph files
        into the same directory, for example glyphs/jjba23.scm and
        glyphs/showcase.scm.

        --list-colors
        List every theme color that glyph files can use, grouped by
        theme, then exit.

        --list-logos
        List the logos available in the resources directory, then exit.

        --list-styles
        List the badge styles (flat, square, shadow, plastic,
        frosted-glass, material, frutiger, neon) with a short
        description of each, then exit.

        --gallery FILE
        Write a self-contained HTML gallery showing every badge from
        --glyphs together with every logo, then exit. Handy for browsing
        the badge and logo libraries.

        --glyphs PATH
        A glyph file, or a directory of .scm glyph files, to render as
        badges in the --gallery page. Pass a directory such as ./glyphs
        to include every glyph file; the gallery groups them by name.

    -V, --version
        Print the version, license and homepage of ggg, then exit.

    -h, --help
        Display this help message and exit.

+----------------------------------------------------------------------------+
CONFIGURING YOUR GLYPHS:
    Colors can be raw hex strings (e.g. "#555") or names from the
    palettes of Catppuccin, Doom, Dracula, Solarized and Modus. A name
    is qualified with its theme, e.g. catppuccin-mocha-red,
    doom-one-blue, dracula-purple, solarized-light-base3 or
    modus-vivendi-green. Run "ggg --list-colors" to see them all.

    Logos are full SVG documents in the resources/logos/ directory, so they
    may contain several paths, groups, gradients, etc. ggg ships a large
    library of tech logos; see CREDITS.org, in the repository root, for their
    sources.
    Run "ggg --list-logos" to see the names, or "ggg --gallery
    ./gallery.html" to browse them visually. In the gallery, click the
    snippet under a badge or logo to copy it to the clipboard.

    A glyph can have any number of sections; each one becomes a segment with
    its own text and colors. A logo belongs to the first section.

    Every glyph can also choose a style, for example (style . neon) or
    (style . frosted-glass). Styles only change the look, never the size or
    the layout of the badge. Run "ggg --list-styles" to see them all.

    Your glyph file is validated before anything is generated: problems such
    as unknown color, logo or style names are reported with a hint, instead
    of producing broken images.

+----------------------------------------------------------------------------+
EXAMPLES:
    ggg -f ~/documents/my-glyphs.scm -d ~/documents/dist

    ggg --file /home/joe/documents/my-glyphs.scm --destination /home/joe/glyphs

    cat ./glyphs/jjba23.scm |
        guix shell -f guix.scm -- ggg --stdin --destination ./dist

    ggg --list-colors

    ggg --gallery ./test/gallery.html --glyphs ./glyphs

    ggg -f ./glyphs/showcase.scm -d ./dist -k -c
